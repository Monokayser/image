Task Management System

Group 2 submission for CSE 504: Software Development Methodology. This project delivers a collaborative CRUD-based web application using Java, React, PostgreSQL, Docker, and GitHub Actions CI/CD.

3. Functional Scope

Module Implemented Features
Authentication Register, login, logout, session-cookie authentication
Workspace Collaboration Create workspace, join by invite code, list members
Task Management Create, view, update, delete tasks with status, priority, assignee, due date
Board View Kanban columns: TODO, IN_PROGRESS, DONE
Comments Task discussion thread for collaboration
Filtering Search, status, priority, assignee, overdue filtering

7. Docker Requirement

The repository includes a multi-stage Dockerfile and a Docker Compose file for local execution.

  • Dockerfile builds React, packages Spring Boot, and creates a runtime image
  • docker-compose.yml starts the application container and PostgreSQL

8. CI/CD Requirement

  • CI: install frontend dependencies, run frontend tests, build frontend, run backend tests
  • CD: build Docker image on main and publish to Docker Hub
